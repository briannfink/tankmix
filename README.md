# SprayTrue legacy-address redirects

The app and its history now live at https://github.com/briannfink/spraytrue and https://briannfink.github.io/spraytrue/ . This repository only preserves old /tankmix/ links (including /preview/, query strings and Auth fragments).

The retirement worker clears CacheStorage, unregisters itself and navigates old-scope clients to the matching new path. It never reads, exports or clears localStorage. Reconnect old installed apps once to receive the update. If an iPhone keeps the old home-screen name, add SprayTrue from the new address after confirming data sync/backup; do not delete an unsynced standalone app.
